How it works

Data flows one way: data/presets.json → state in app.js → physics and integration → drawing. Each file has one job.

  1. Model (physics.js). In units where the stars are 1 apart and the binary period is 2π, the body feels the stars' gravity plus the centrifugal and Coriolis terms of the rotating frame: x″ = 2y′ + Ωₓ, y″ = −2x′ + Ω_y, with Ω = ½(x²+y²) + (1−μ)/r₁ + μ/r₂.
  2. Equilibria. Points where ∇Ω = 0. L4/L5 are exact (r₁ = r₂ = 1); L1–L3 are roots of Ωₓ on the x-axis, found by bisection in a bracket that holds exactly one sign change.
  3. The field (scene.js). 2Ω is sampled on a grid. The body can only be where 2Ω ≥ C (C is its Jacobi constant), so the shaded zone is where it can never go. Contours are traced with marching squares; the coloured ones are the values of C at L1, L2, L3 — the energies at which each gateway opens.
  4. Linearisation. Near an equilibrium the motion obeys ζ′ = Aζ. Its eigenvalues follow from λ⁴ + (4−Ωₓₓ−Ω_yy)λ² + (ΩₓₓΩ_yy−Ωₓ_y²) = 0. A real eigenvalue is an exponential escape route (arrows); an all-imaginary set means bounded libration. L4/L5 are stable only when 27μ(1−μ) < 1 (μ < 0.0385).
  5. Integration (integrator.js). Adaptive Dormand–Prince 5(4) with tolerance 1e-11. Steps shrink near a star and grow in quiet regions. The Jacobi constant should never change, so its error is plotted as an honest measure of accuracy.
  6. Frames. Trails are stored in the rotating frame together with the time of each point. The inertial view simply rotates every stored point by its own time, which is why a Trojan looks like a body circling with the binary.

Adding presets. Edit data/presets.json (see its _help field) or load another file with “Add presets…”. Opening index.html directly from disk blocks fetch; serve the folder with python -m http.server or use the file picker.
